작동 방식

1

PC 연결

설치 명령을 실행하면 화면에 연결 코드가 나옵니다. 대시보드에 입력하면 끝 — 이후 부팅 때마다 자동으로 참여합니다.

2

배포

저장소를 고르고 이름을 정하면 name.krl.kr 주소가 즉시 발급됩니다. 환경변수·도메인·확장은 대시보드에서.

3

분산 실행

앱이 여러 PC에 복제되어 트래픽이 분산됩니다. 가동률, 로그, 크레딧 사용량을 실시간으로 확인하세요.

GitHub 자동 배포

push 하면 웹훅으로 자동 재배포합니다.

다중 노드 복제

인스턴스 개수, 지역, 서로 다른 제공자 분산을 직접 설정합니다.

오토스케일

트래픽에 따라 인스턴스를 자동으로 늘리고 줄입니다.

자동 장애 복구

노드 연결 끊김·과부하를 감지해 다른 노드로 옮기고, 복구된 노드는 자동 재참여합니다.

환경변수 & Secret

키/값 관리, Secret 은 저장 후 다시 노출되지 않습니다.

실시간 로그 & 지표

인스턴스별 로그, 요청 수, 가동률, 비용을 한 화면에서.

Spot / Priority / Private

저렴한 중단 가능 호스팅, 안정 노드 우선 배치, 내 노드 그룹에서만 실행.

Docker 샌드박스

사용자 코드는 컨테이너에서 격리되어 제공자의 PC를 보호합니다.

Node Reputation

가동률·안정성 기반 신뢰도로 좋은 노드가 우선 선택됩니다.

요금 — 현금이 아니라 크레딧

PC 자원을 제공하면 크레딧이 쌓이고, 호스팅에 사용합니다. 인스턴스 1개 기준 시간당 크레딧입니다.

옵션
고가용성 +20% · 우선 배치 +15% · 지역 지정 +10% · Spot −50%
데이터 전송

CPU·RAM·디스크·대역폭 제공량 + 가동 시간·신뢰도·장기 유지 보너스, 호스팅 사용료의 85%

내 PC 연결하기

설치 → 표시된 코드를 대시보드의 My Nodes → 내 PC 연결에 입력. 이후 자동 시작·자동 호스팅.

자주 묻는 질문

내 PC가 안전한가요?

정적 사이트는 에이전트 내부 파일 서버로만 제공되어 사용자 코드가 실행되지 않습니다. Node/Python/Docker 앱은 CPU·메모리·프로세스 수가 제한된 Docker 컨테이너에서만 실행되며, Docker 가 없으면 코드 실행을 거부합니다. 제공 자원은 직접 정한 만큼만 사용되고 언제든 일시 중지·연결 해제할 수 있습니다.

PC를 사용 중일 때도 느려지나요?

“유휴 시에만 제공”을 켜면 PC 사용률이 높을 때 새 인스턴스를 받지 않고, 실행 중인 인스턴스는 다른 노드로 옮깁니다.

크레딧은 어떻게 쌓이나요?

노드가 온라인인 동안 제공량에 비례해 쌓이고, 내 노드에서 다른 사람의 서비스가 실행되면 그 사용료의 85%가 추가로 적립됩니다. 신규 노드·24시간 안정 가동·장기 유지 보너스도 있습니다.

노드가 꺼지면 내 서비스는요?

하트비트가 끊기면 해당 노드를 즉시 제외하고 다른 노드에 대체 인스턴스를 띄웁니다. 인스턴스를 2개 이상(서로 다른 제공자)으로 설정하면 단일 노드 장애에도 중단 없이 응답합니다.

상태 비저장(stateless) 서비스만 되나요?

현재는 그렇습니다. 영구 디스크/DB 는 아직 제공하지 않으므로 외부 DB 를 쓰거나 상태를 저장하지 않는 서비스에 적합합니다.

서브도메인은 몇 개까지 받나요?

서비스당 1개입니다. 먼저 가져간 이름이 임자이며, 이름을 바꾸면 이전 이름은 반납됩니다.
